# Portfólio — Vinicius

Portfólio pessoal desenvolvido com **Vue 3**, **Vite** e **Tailwind CSS**, com tema claro/escuro, animações de scroll e layout responsivo.

## Tecnologias

- [Vue 3](https://vuejs.org/) com `<script setup>`
- [Vite](https://vite.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Iconify](https://iconify.design/) para ícones
- [Swiper](https://swiperjs.com/) para o carrossel de projetos
- [AOS](https://michalsnik.github.io/aos/) para animações ao rolar
- [vue-countup-v3](https://github.com/jizai1125/vue-countup-v3) para os contadores

## Rodando localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

O resultado fica em `dist/`.
